# Changelog

## 0.2.1 (2026-11-06)

- Tested with Attune 16001-37.
- Attune's new "Will not do" checkbox at the bottom right of the chain has the same flat look, and attunements you set
  aside are greyed in the list.
- Character Progression chains: the cards show the name of each goal, and their counts update while the chain is open.
- Fix: a character without a second name is recognised.

## 0.2.0 (2026-11-05)

- Built from the same source as BeautifulSkins: the Attune skin now lives in the folder `BeautifulAttune_Skin`, which
  BeautifulAttune loads. Both folders belong together. Your settings are kept.
- **Attune: Next**, Attune's second window with the next step of every attunement, has the same flat look.
- Two new buttons in the window header, next to the settings button: one switches the "Attune: Next" window on and off
  (its own close button switches it off for good, this brings it back), one opens Attune's own options.
- Tested with Attune 16001-35.
- **Thirteen themes** (instead of seven) with a theme gallery and a **theme editor** for your own themes, with live
  contrast check and export / import. New installs without EllesmereUI start with the Midnight theme.
- Options pages: General (appearance, language, minimap, EllesmereUI) and Attune (look, search and zoom, parts).
- With BeautifulSkins installed as well, BeautifulAttune steps back (BeautifulSkins contains the same skin).
- The minimap button opens the settings; Attune is in its right-click menu. `/battune minimap` became
  `/beautifulattune minimap`.
- Fix: dragging the list's scroll bar follows the mouse.

## 0.1.0 (beta)

First public version, built for WoW: Forever (Interface 16001) and tested with Attune 16001-34.

- Flat window in the active theme: header with the switch between attunements and results, settings and close; status
  bar, survey menu and resize grip in the same style; window scale 70–130 %.
- List with section headings, icons, level ranges and progress; Attune's icon grid hidden (optional).
- Chain cards with status strips, modern or classic status colours, three line weights, head card with the dungeon
  picture (banner, background or off).
- Zoom bar from 10 to 150 %, fit the whole chain, Ctrl + mouse wheel, remembered between sessions.
- Search with filters for attunements, quests, NPCs, items and zones; IDs and short names; keyboard control; jump to the
  step with a highlight; marks in the open chain.
- Quest detail panel, rewards, quest giver hint and results table in the same style.
- Settings window (Appearance, Search & zoom, Modules, Info) and, with EllesmereUI, the section "Attune Skin" in its
  options window; minimap button and addon compartment entry.
- Seven themes, accent colours, bundled fonts; readable light themes without text shadows.
- English and German.
